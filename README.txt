BURU DISOM SANGAT — WEBSITE SETUP

FILES
- index.html: website content and sections
- style.css: deep purple and gold design
- script.js: mobile menu and automatic copyright year

BEFORE PUBLISHING
1. Open index.html in a text editor.
2. Replace every occurrence of YOUR_CHANNEL_HANDLE with your YouTube handle (without @ if you prefer; keep the @ in the URL).
   Example URL: https://www.youtube.com/@YourRealChannel
3. Replace VIDEO_ID_1, VIDEO_ID_2, VIDEO_ID_3 with the IDs of three public YouTube videos.
   A video ID is the part after v= in https://www.youtube.com/watch?v=VIDEO_ID
   For Shorts, use the ID from the Shorts URL.
4. Replace YOUR_EMAIL@example.com with an email address you want visitors to use.
5. Replace the sample video titles/descriptions.
6. Save all files in the same folder.

PREVIEW
Double-click index.html to open it in a web browser. Internet access is needed for Google Fonts, remote gallery photos and YouTube embeds.

PUBLISH FREE WITH GITHUB PAGES
1. Create/sign in to a GitHub account at https://github.com/
2. Create a new public repository named buru-disom-sangat-website.
3. Upload index.html, style.css and script.js to the repository's main/root folder.
4. Open repository Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait for GitHub Pages to publish. Your site address will look like:
   https://YOUR-GITHUB-USERNAME.github.io/buru-disom-sangat-website/
8. Open the address and test every menu link, video and contact link.

IMPORTANT
- The YouTube channel handle and video IDs are placeholders until you replace them.
- Gallery photos are sample remote images. Replace them with photos you own or have permission to use.
- Do not publish private phone numbers or personal information.
- You can later connect a custom domain through repository Settings → Pages.
